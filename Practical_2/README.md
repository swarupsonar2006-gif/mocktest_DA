# Practical 2: Student Marks Analysis

## Aim

To analyze student marks with pandas, classify results, and calculate summary values.

## What the scripts do

- Create a DataFrame of student names and marks.
- Assign a result category based on each student's marks: Distinction, Pass, or Fail.
- Display the dataset and each student's result.
- Calculate the average, highest, and lowest marks.

## Requirements

- Python 3
- pandas

Install pandas if needed:

```powershell
python -m pip install pandas
```

## Run

From this folder, run any of the numbered scripts:

```powershell
python .\1.py
```

Replace `1.py` with `2.py` or `3.py` to run another copy.
