# Practical 3: Student Data Exploration

## Aim

To explore a student dataset using filtering, sorting, grouping, and descriptive statistics in pandas.

## What the scripts do

- Create a sample dataset with student names, departments, and marks.
- Filter students whose marks are greater than 60.
- Sort the dataset by marks in ascending and descending order.
- Calculate average marks for each department.
- Calculate the overall mean, median, and mode of marks.

## Requirements

- Python 3
- pandas

Install pandas if needed:

```powershell
python -m pip install pandas
```

## Run

From this folder, run any of the numbered scripts:

```powershell
python .\1.py
```

Replace `1.py` with `2.py` or `3.py` to run another version.
