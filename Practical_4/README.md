# Practical 4: Data Type and Value Transformation

## Aim

To collect student information and transform numeric, text, and date columns using pandas.

## What the scripts do

- Ask for each student's name, age, department, and admission date.
- Convert age values to integers.
- Trim and title-case names, and title-case department names.
- Parse admission dates in `DD-MM-YY` format.
- Extract the year, month, and day from each admission date.
- Display the data and its types before and after transformation.

## Requirements

- Python 3
- pandas

Install pandas if needed:

```powershell
python -m pip install pandas
```

## Run

From this folder, run any of the numbered scripts:

```powershell
python .\1.py
```

Enter admission dates in `DD-MM-YY` format when prompted. Replace `1.py` with `2.py` or `3.py` to run another copy.
