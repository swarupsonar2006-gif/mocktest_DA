# Practical 6: Interactive Sales Dashboard

## Aim

To build an interactive sales dashboard with Plotly Dash, using filters and charts to explore sales metrics.

## What the scripts do

- Generate a sample sales dataset with dates, regions, categories, units, prices, and revenue.
- Provide filters for region, category, and date range.
- Update key performance indicators for revenue, orders, average order value, and units sold.
- Display monthly revenue trends and revenue breakdowns by category and region.

## Requirements

- Python 3
- NumPy
- pandas
- Plotly
- Dash

Install the dependencies if needed:

```powershell
python -m pip install numpy pandas plotly dash
```

## Run

From this folder, run any of the numbered scripts:

```powershell
python .\1.py
```

Replace `1.py` with `2.py` or `3.py` to run another copy. Open [http://127.0.0.1:8050](http://127.0.0.1:8050) in a browser to use the dashboard. Stop the server with `Ctrl+C` in the terminal.
