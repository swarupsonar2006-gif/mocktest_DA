# Practical 1: DataFrame Operations

## Aim

To create and explore a pandas DataFrame using row filtering, sorting, grouping, and basic statistical operations.

## What the scripts do

- Create a sample DataFrame containing names, ages, cities, mobile numbers, zodiac signs, and hobbies.
- Select rows for people older than 22.
- Sort the data by age in ascending and descending order.
- Group records by city.
- Calculate the mean, median, and mode of the ages.

## Requirements

- Python 3
- pandas

Install pandas if needed:

```powershell
python -m pip install pandas
```

## Run

From this folder, run any of the numbered scripts:

```powershell
python .\1.py
```

Replace `1.py` with `2.py` or `3.py` to run another copy.
